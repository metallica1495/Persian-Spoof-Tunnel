# مدیریت فارسی Spoof Tunnel

اسکریپت منویی فارسی برای نصب و مدیریت پنل رسمی **Spoof Tunnel** در سرورهای Linux.

> این مخزن یک ابزار مدیریتی مستقل است؛ هسته اصلی Spoof Tunnel را بازنویسی یا تغییر نمی‌دهد. نصب هسته و پنل از Releaseها و اسکریپت رسمی پروژه بالادستی انجام می‌شود.

## امکانات نسخه اولیه

- تشخیص Linux و معماری‌های x86_64 و ARM64
- منوی کاملاً فارسی در ترمینال
- نصب و به‌روزرسانی با اسکریپت نصب رسمی پروژه اصلی
- مشاهده وضعیت سرویس systemd و گزارش‌ها
- تهیه نسخه پشتیبان از داده‌های پنل
- بازیابی نسخه پشتیبان
- حذف فایل اجرایی و سرویس پنل با حفظ پوشه داده‌ها

## نصب و اجرا

با دسترسی root اجرا کنید:

```bash
apt-get update && apt-get install -y curl
curl -fL https://raw.githubusercontent.com/metallica1495/Persian-Spoof-Tunnel/main/install.sh -o install.sh
bash install.sh
```

یا پس از دریافت فایل:

```bash
chmod +x install.sh
sudo ./install.sh
```

## پیش‌نیاز و سازگاری

- Linux با systemd
- معماری x86_64 یا ARM64
- دسترسی root
- ابزار curl

اسکریپت در نسخه فعلی، نصب را به‌صورت خودکار از طریق نصب‌کننده رسمی پروژه بالادستی انجام می‌دهد. سازگاری نهایی باینری‌های هسته به Release رسمی و معماری سرور وابسته است.

## مسیرهای مهم

| مورد | مسیر |
|---|---|
| داده‌ها و تنظیمات پنل | `/etc/spoof-panel` |
| فایل اجرایی پنل | `/usr/local/bin/spoof-panel` |
| سرویس systemd | `/etc/systemd/system/spoof-panel.service` |
| پشتیبان‌ها | `/root/persian-spoof-tunnel-backups` |

## امنیت

- رمز عبور، اطلاعات ورود، دیتابیس و تنظیمات سرور را در GitHub قرار ندهید.
- فایل‌های پشتیبان ممکن است حاوی اطلاعات حساس باشند؛ دسترسی آن‌ها محدود به root است.
- نصب‌کننده رسمی از مخزن بالادستی دریافت می‌شود؛ قبل از اجرا امکان لغو وجود دارد.
- برای پنل وب، دسترسی را با فایروال و در صورت امکان reverse proxy همراه HTTPS محدود کنید. نصب‌کننده بالادستی ممکن است پنل را روی HTTP راه‌اندازی کند؛ اطلاعات ورود را از طریق شبکه ناامن ارسال نکنید.
- فقط روی سرورها و شبکه‌هایی استفاده کنید که مالک آن هستید یا مجوز مدیریت آن‌ها را دارید.
