# مدیریت فارسی Spoof Tunnel

ابزار منویی فارسی برای نصب و مدیریت هسته و پنل رسمی **Spoof Tunnel** روی Linux. هسته از پروژه بالادستی دریافت می‌شود؛ این مخزن آن را بازنویسی نمی‌کند.

> استفاده را به سرورها و شبکه‌هایی محدود کنید که مالک آن‌ها هستید یا مجوز صریح مدیریتشان را دارید. این ابزار تضمین‌کننده عبور از فایروال، پایداری یا ناشناس‌ماندن نیست.

## امکانات فعلی

- تشخیص Linux و معماری x86_64 / ARM64
- نصب باینری هسته از Release رسمی و بررسی SHA256 با فایل checksums همان Release
- ساخت کانفیگ تعاملی برای نقش‌های `local` و `remote`
- انتخاب پروتکل‌های ارسال و دریافت مطابق CLI نسخه v3
- ساخت سرویس systemd، مشاهده وضعیت، گزارش‌ها و راه‌اندازی مجدد
- پشتیبان‌گیری از کانفیگ هسته
- نصب پنل رسمی و مشاهده وضعیت/گزارش‌ها و پشتیبان‌گیری از داده پنل

## نصب و اجرا

پیش‌نیازها: Linux با systemd، دسترسی root، `curl` و `python3`.

```bash
apt-get update && apt-get install -y curl python3
curl -fL https://raw.githubusercontent.com/metallica1495/Persian-Spoof-Tunnel/main/install.sh -o install.sh
sudo bash install.sh
```

## راهنمای سریع

1. گزینه **۱**: نصب هسته رسمی.
2. گزینه **۲**: انتخاب نقش `local` یا `remote` و وارد کردن مقادیر شبکه.
3. اگر از فایل IP استفاده می‌کنید، فایل باید از قبل روی همان سرور وجود داشته باشد، مسیر آن مطلق و قابل‌خواندن باشد و در قالب مورد قبول هسته، یک IPv4 در هر خط داشته باشد.
4. پس از ذخیره کانفیگ، در صورت تأیید شما سرویس systemd فعال می‌شود.
5. گزینه‌های ۳ تا ۶ برای وضعیت، لاگ، راه‌اندازی مجدد و پشتیبان‌گیری هسته هستند.

**توجه:** این نسخه Release هسته را روی `v3.1.0-beta.0` پین کرده است تا نصب‌ها قابل‌تکرار باشند. این نسخه از ساختار `local/remote` و تنظیمات v3 استفاده می‌کند؛ فایل‌های کانفیگ v1 با آن سازگار نیستند. گزینه XDP اختیاری است و فقط در صورت آشنایی با کارت شبکه و کرنل سرور آن را وارد کنید.

برای ایجاد یک تونل، باید هر دو سمت با اطلاعات مکمل تنظیم شوند. `remote` باید IP واقعی سمت local و پورت دریافت آن را بشناسد؛ سمت local نیز IP واقعی سمت remote و پورت شنود آن را وارد می‌کند. مقادیر IP و پورت را از مدیر سرور/شبکه خود دریافت کنید. این ابزار IPهای متعلق به دیگران را برای شما فراهم نمی‌کند.

## مسیرهای مهم

| مورد | مسیر |
|---|---|
| هسته اجرایی | `/usr/local/bin/spoof` |
| کانفیگ هسته | `/etc/spoof-tunnel/config.json` |
| سرویس هسته | `spoof-tunnel.service` |
| داده‌های پنل | `/etc/spoof-panel` |
| باینری پنل | `/usr/local/bin/spoof-panel` |
| پشتیبان‌ها | `/root/persian-spoof-tunnel-backups` |

فایل کانفیگ هسته با مجوز `600` و پوشه آن با مجوز محدود root ساخته می‌شود. کانفیگ‌ها، فایل‌های IP، رمزهای پنل و پشتیبان‌ها را در GitHub بارگذاری نکنید.

## مدیریت دستی سرویس

```bash
systemctl status spoof-tunnel
journalctl -u spoof-tunnel -n 100 --no-pager
systemctl restart spoof-tunnel
```

## امنیت و محدودیت‌ها

- برای اجرای هسته، دسترسی root لازم است؛ هسته از قابلیت‌های شبکه سطح پایین استفاده می‌کند.
- پورت‌های لازم را فقط برای آدرس‌ها و میزبان‌های موردنیاز در فایروال باز کنید.
- اگر پنل را نصب می‌کنید، دسترسی آن را محدود کنید و در صورت امکان HTTPS را با reverse proxy تنظیم کنید.
- نسخه فعلی پشتیبان‌گیری و بازیابی کامل پنل را در منوی مدیریتی ندارد؛ پیش از تغییرات مهم از داده‌های پنل جداگانه نسخه پشتیبان بگیرید.
- نصب و اجرای واقعی روی سرورهای متنوع هنوز به آزمون میدانی نیاز دارد.
